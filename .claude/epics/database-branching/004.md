# Git Hook Integration

## Overview
Implement Git hook integration to automatically trigger database snapshots on branch operations. This provides seamless workflow integration without manual intervention.

## Acceptance Criteria

### Core Hook Implementation
- [ ] Post-checkout hook detects branch switches and new branch creation
- [ ] Post-merge hook captures merge operations with conflict resolution data
- [ ] Hook installation preserves existing hooks through chaining mechanism
- [ ] Safe uninstallation restores original hook state
- [ ] Branch detection distinguishes between file checkout and branch operations

### Integration Points
- [ ] Hooks invoke snapshot engine through CLI interface
- [ ] Error handling prevents Git operation interruption
- [ ] Logging captures hook execution for debugging
- [ ] Configuration controls hook behavior and snapshot policies
- [ ] Performance optimization ensures minimal Git workflow impact

### Safety and Reliability
- [ ] Existing hook preservation through wrapper pattern
- [ ] Atomic installation prevents partial hook states
- [ ] Rollback capability for failed installations
- [ ] Hook validation before activation
- [ ] Graceful degradation when snapshot fails

## Technical Details

### Hook Architecture
```bash
# .git/hooks/post-checkout wrapper
#!/bin/bash
# Original hook preservation
if [ -f ".git/hooks/post-checkout.original" ]; then
    .git/hooks/post-checkout.original "$@"
fi
# dbranching integration
dbranching hook post-checkout "$@"
```

### Branch Detection Logic
- Distinguish file checkout vs branch switch via Git hook parameters
- Parse `git rev-parse --abbrev-ref HEAD` for current branch
- Compare previous and current refs to detect branch changes
- Handle detached HEAD states and temporary branches

### Error Handling Strategy
- Non-zero exit codes must not prevent Git operations
- Log errors to dedicated hook log file
- Provide user feedback through stderr without blocking
- Retry mechanism for transient failures
- Fallback to manual snapshot creation on persistent errors

### Performance Considerations
- Asynchronous snapshot creation to avoid blocking Git
- Early exit conditions for non-branch operations
- Minimal filesystem access during hook execution
- Background process handling for long-running snapshots

## Implementation Notes

### Installation Process
1. Backup existing hooks to .original files
2. Create wrapper hooks that chain original + dbranching
3. Set executable permissions and validate syntax
4. Test hooks with dry-run mode
5. Activate hooks atomically
