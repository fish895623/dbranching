## Technical Details

### Configuration Schema
```yaml
# .dbranching.yaml
version: "1.0"

# Database connections
databases:
  default:
    driver: postgresql
    host: localhost
    port: 5432
    database: myapp_development
    username: ${DB_USER}
    password: ${DB_PASSWORD}
    ssl_mode: prefer
    pool_size: 10
    connect_timeout: 30s

# Storage configuration
storage:
  path: ${HOME}/.dbranching/snapshots
  compression:
    algorithm: gzip
    level: 6
  retention:
    default:
      max_age: 30d
      max_count: 100
    patterns:
      - branches: ["main", "master"]
        max_age: 90d
        max_count: 50
      - branches: ["feature/*"]
        max_age: 7d
        max_count: 10

# Git integration
git:
  hooks:
    enabled: true
    auto_install: true
  branches:
    auto_snapshot: ["main", "develop"]
    ignore: ["temp/*", "wip/*"]

# CLI behavior
cli:
  output_format: table
  color: auto
  progress_bars: true
  confirm_destructive: true

# Logging
logging:
  level: info
  file: ${HOME}/.dbranching/logs/dbranching.log
  rotate_size: 10MB
  rotate_count: 5
```

### Configuration Hierarchy
1. **System**: `/etc/dbranching/config.yaml`
2. **User**: `${HOME}/.config/dbranching/config.yaml`
3. **Project**: `.dbranching.yaml` (in project root)
4. **Environment**: Environment variables with `DBRANCHING_` prefix
5. **CLI Flags**: Command-line overrides

### Environment Variable Mapping
```bash
DBRANCHING_DATABASES_DEFAULT_HOST=localhost
DBRANCHING_STORAGE_PATH=/custom/path
DBRANCHING_GIT_HOOKS_ENABLED=true
DBRANCHING_CLI_OUTPUT_FORMAT=json
DBRANCHING_LOGGING_LEVEL=debug
```
